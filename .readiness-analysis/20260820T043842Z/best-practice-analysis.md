범위: 현재 ITADAKI 프로젝트와 공개 근거만 사용. 제품 코드·설정·의존성·인터넷에 공개된 앱·저장 기록은 수정하지 않았다.

## 1. 대상 서비스 한 문단 설명

ITADAKI는 한국어 사용자가 도쿄 일본 식당을 검색·비교하고, 가격·규칙·혼자 방문 가능 여부·공식 출처·확인일을 바탕으로 방문을 결정하도록 돕는 공개 정적 웹앱 시험판이다. 예약 대행·결제·계정은 v4 범위에서 제외하며, 현재 표시 가능 실제 식당은 3곳이고 화면 흐름용 합성 예시는 6곳이다.

## 5. 합성된 이상 기준

1. 시작 조건을 빠르게 정하고 첫 탐색을 끝낸다.
2. 모든 방문 판단 정보에 출처·확인일·불확실성을 남긴다.
3. 검색·필터·정렬·빈 결과 대안을 일관되게 제공한다.
4. 상세에서 가격·접근·규칙·식이·혼자 방문을 비교한다.
5. 찜·비교 목록을 저장·삭제·공유한다.
6. 정정 요청을 접수하고 처리 상태와 기한을 공개한다.
7. 설치·오프라인·재연결을 실제 기기에서 확인한다.
8. 키보드·스크린리더·확대 화면 접근성을 확인한다.
9. LCP·CLS·TBT 성능 목표와 측정 추세를 둔다.
10. robots·sitemap·구조화된 메타데이터를 제공한다.
11. 운영자·약관·개인정보·삭제 절차를 실제 흐름에 맞춘다.
12. 보안 헤더·오류 감시·복구·배포 전 통과 조건을 운영한다.
13. 검색·상세·공식 링크·정정의 성공률과 데이터 최신성을 측정한다.

## 7. 예비 수준 점수와 증거 완성도

Readiness Hub 엔진은 197개 항목·40개 필수 통과 조건을 기준으로 입력된 증거만 계산했다. 모바일 16.67점(증거 진행률 6%), PC 웹 22.35점(19%), 통합 17.86점이며 모두 `L1? 판정 보류`다. 이는 제품 자체의 최종 품질 점수가 아니라, 대규모 렌즈에 비해 입력 증거가 아직 적다는 신호다. 미확인은 0점으로 넣지 않았다.

시장 상대 위치는 비교 서비스 5곳 안에서 16.67백분위로 계산됐지만, 기능 폭·도달·성능에서 큰 서비스와의 초기 단계 비교이고 분석자 정규화 점수이므로 시장 점유율·매출·평점의 주장이 아니다.

공개 엔진 v1.0.1과 core 렌즈 v2.1.0을 분석 폴더에만 내려받아 실행했다. JSON·Markdown 결과는 같은 폴더에 있다. 197개 항목 중 모바일 10개, PC 웹 33개만 점수 또는 미확인으로 명시됐고 다수는 미평가이므로 점수는 ‘출시 준비도 확정’이 아니다. 결제·네이티브 앱·현 위치 수집처럼 현재 범위에 맞지 않는 일부 항목만 `na`로 표시했다.

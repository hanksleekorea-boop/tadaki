# 첫 작업 따라하기 (계획 예시)

예시 작업은 `TASK-1-001`이다.

1. 작업 폴더가 프로젝트 루트인지 확인한다.
2. `git status --short`가 비어 있는지 읽기 전용으로 확인한다.
3. `04_코드/data/tokyo/`의 후보 파일과 기존 배치를 백업 경로에 복사한다(개발 실행 때만).
4. 후보 023의 공식 사이트·주소·영업·가격·예약·식단 필드를 각각 확인한다.
5. 확인일과 URL을 증거 원장에 기록한다.
6. 충돌 값은 병기하고 임의로 선택하지 않는다.
7. 필수 필드 누락이면 표시 금지 상태로 둔다.
8. 자동 스키마 검사를 실행한다.
9. 브라우저 결과에서 표시·공식 링크를 확인한다.
10. 실패 시 새 자료를 폐기하지 말고 기존 자산을 유지한다.
11. 운영자 검토 서명을 받는다.
12. 증거 경로·다음 후보·남은 필드를 인계문에 기록한다.

이번 분석 실행에서는 위 작업을 수행하지 않았다.

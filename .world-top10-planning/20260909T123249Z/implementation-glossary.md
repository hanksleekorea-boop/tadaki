# 구현 용어집

- `progress.json`: 공개판의 판·콘텐츠·시험 상태를 읽는 데이터.
- `release-gate.json`: 상용화 차단 조건의 기계 판독 정본.
- `OWN-*`: 프로젝트 내부 근거.
- `GAP-*`: 증거와 목표 사이의 차이.
- `REQ-*`: 검증 가능한 제품 요구사항.
- `TASK-*`: 한 AI가 수행할 원자 작업. 현재는 계획 상태.
- `TEST-*`: 입력·절차·기대값이 있는 시험.
- `EVD-*`: 완료 증거 자리 또는 실제 증거.
- `DISCOVERY_REQUIRED`: 파일·기호·외부 사실 확인 후 구현 가능.
- `WAITING_EXTERNAL`: 운영자·기기·계정·전문가가 필요.
- B드라이브: 사용자가 영구 제외한 저장소. 어떤 작업에서도 연결하지 않는다.

# 사용자 여정 대결 설계

실제 톱10 대결은 외부 재검증 후 실행한다. 현재 계획의 공통 시나리오는 다음과 같다.

1. 한국어 사용자가 “이케부쿠로 혼밥 저녁 3,000엔 이하”를 입력한다.
2. 권역·장르·예산·상황 필터를 적용한다.
3. 결과의 근거 상태·확인일·공식 링크를 이해한다.
4. 식당 한 곳을 저장하고 여행 후보에 추가한다.
5. 두 곳을 비교하고 지도/예약 공식 링크로 이동한다.
6. 연결이 끊긴 상태에서 저장 자료를 다시 연다.

비교 지표: 첫 결과까지 시간, 필터 성공률, 근거 이해, 저장 완료율, 오류 복구, 오프라인 회복, 접근성 조작 수. 실제 사용자 만족도나 시장 성공을 뜻하지 않는다.

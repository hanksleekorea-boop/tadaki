# 초정밀 벤치마킹 보고서

## 계산 가능 범위

2026-08-24의 역사 비교는 30개 서비스를 7개 묶음으로 서술했지만, 이번 실행에서 최신 외부 근거를 재수집하지 않았다. 따라서 현재 톱10 평균·백분위·세계 순위를 계산하지 않는다. `benchmark-matrix.json`의 네 개 내부 행은 격차 추적용이며 평균 산출 대상이 아니다.

## 후속 동일 지표 비교 절차

`DISCOVERY-001`에서 고정 10개를 재검증 → `METRIC-*` 1,600개를 중복 제거 → 0~5 점과 증거 ID 입력 → 평균·중앙값·표준편차를 재계산 → 낮은 표본 경고를 표시한다. 미확인 값은 0점으로 바꾸지 않는다.
